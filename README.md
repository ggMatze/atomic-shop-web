# Fallout 76 Atomic Shop – Transparent Web Version

This project is a faithful recreation of the Fallout 76 Atomic Shop, built to present all shop offers clearly, accurately, and transparently.  
It aims to show how the shop could look if images, labels, and prices were properly organized and easy to understand.

---

## Project Goals

- Recreate the Atomic Shop using HTML, CSS, and JavaScript  
- Use correct and properly ordered images for all bundles and items  
- Include clear label explanations (for example, `NEW*` → item not actually new)  
- Display prices in real-world currencies (€, $, etc.) instead of Atoms  
- Provide a structured, easy-to-navigate layout  
- Load shop data from a JSON structure similar to `Providers/ShopData.json`

---

## Technical Overview

- Built with HTML, CSS, and Vanilla JavaScript  
- Dynamic tile system for bundles and items  
- Label system for NEW, SALE, 1ST, and other tags  
- Correct image order and consistent sizing  
- Overlay with title, description, image carousel, and item list  
- Planned: JSON data integration for live updates

---

## Background

The original in-game Atomic Shop contains several presentation issues:

- Missing or incorrect images  
- Images showing unrelated or confusing content  
- Unsorted or inconsistent item layouts  
- Misleading labels on previously released items  
- Prices shown only in Atoms

---

## Purpose

This project uses the same time-based data and timers as the in-game shop,  
but focuses on clarity and transparency.  
All offers are displayed with accurate visuals, real-world currency options,  
and clear labeling so that players can see exactly what is being offered —  
without confusion or misleading presentation.
